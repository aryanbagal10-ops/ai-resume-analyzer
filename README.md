# 🤖 AI Resume Analyzer

An AI-powered web application built with Python and Streamlit that analyzes resumes and compares them with job descriptions.

## 🚀 Live Demo

👉 https://aryanbagal10-ops-ai-resume-analyzer-app-enobun.streamlit.app/

## ✨ Features

- 📄 Upload resume in PDF format
- 🧠 Extract text from PDF
- 💻 Detect technical skills
- 🎯 Calculate Job Match Score
- 📊 Calculate Resume Quality Score
- ✅ Show matched skills
- ❌ Show missing skills
- 💡 Provide resume improvement suggestions
- 📋 View extracted resume text
- 🌐 Live Streamlit web application

## 🛠️ Tech Stack

- Python
- Streamlit
- PyPDF2


- Git
- GitHub

## 🔄 How It Works

1. Upload your resume PDF.
2. Paste the job description.
3. Click **Analyze Resume**.
4. The application extracts text from the resume.
5. Technical skills are detected.
6. Resume skills are compared with job requirements.
7. Job Match Score is calculated.
8. Resume Quality Score is calculated.
9. Missing skills and improvement suggestions are displayed.

## 📊 Analysis

The application provides:

- 🎯 Job Match Percentage
- 📄 Resume Quality Percentage
- 💻 Detected Skills
- ✅ Matched Skills
- ❌ Missing Skills
- 💡 Improvement Suggestions
